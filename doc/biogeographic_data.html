Use biogeographic ranges as constraints

Maël Doré

2026-11-26

Grafting can be constrained by species attributes described by stochastic character maps (simmap) of the backbone phylogeny. This tutorial explains how to use biogeographic ranges as attributes, i.e., geographically-informed grafting: a missing taxon is only grafted on the branches where its lineage could have lived in its known range. A range is a set of areas (e.g., "A", "AB"), and the stochastic map shows how the range of the lineages evolved along the backbone (e.g., from a BioGeoBEARS analysis).

The key is the argument treat_states_as_ranges, which tells the grafting functions how to match the allowed ranges of a taxon with the ranges of the map:

  1. Exact matching (treat_states_as_ranges = FALSE, the default): ranges are unrelated states, like for categorical traits (e.g., colors). A taxon allowed in "A" can only be grafted on branch pieces where the map is exactly in "A".
  2. Range matching (treat_states_as_ranges = TRUE): a taxon allowed in "A" can be grafted wherever the lineage includes the area "A": "A", "AB", "ABC", etc.

We compare the two options side by side, with the same data, so that the differences shown come from the matching type argument (treat_states_as_ranges).

Ranges must be coded as in BioGeoBEARS: one capital letter per area, and the letters of a multi-area range in alphabetical order ("AB", not "BA").

The list of missing taxa has the usual structure (see vignette("format_inputs")), with allowed ranges in the allowed_states item. Some taxa have their own allowed ranges, the others have NULL and use the global allowed_states argument of the grafting function:

1/ Which mapped range match an allowed range?

The matching rule is the only difference between the two options. For each range of the map, we list the allowed ranges that can be grafted on it, under each matching type option:

# ------ Which allowed ranges match each range of the map? ------ #

map_ranges <- c("A", "B", "AB", "BC")
allowed <- c("A", "B", "AB", "BC")

# A range of the map matches an allowed range if it contains all of its areas
contains <- function(map_range, allowed_range)
  all(strsplit(allowed_range, "")[[1]] %in% strsplit(map_range, "")[[1]])

data.frame(Map_range = map_ranges,
           Exact_matching = map_ranges,
           Range_matching = sapply(map_ranges, function(r) 
              paste(allowed[sapply(allowed, contains, map_range = r)], collapse = ", ")),
           row.names = NULL)
#>   Map_range Exact_matching Range_matching
#> 1         A              A              A
#> 2         B              B              B
#> 3        AB             AB       A, B, AB
#> 4        BC             BC          B, BC

With exact matching (treat_states_as_ranges = FALSE), a branch in "AB" is only available for taxa allowed in "AB".

With range matching (treat_states_as_ranges = TRUE), it is also available for taxa allowed in "A" or "B", which is accounting for a subset sympatric speciation event: a lineage that lived in "AB" can produce a descendant that lives in "A" only such as (AB) -> (AB), (A). Conversely, a taxon allowed in "AB" cannot be grafted on a branch in "A".

When a taxon is grafted on a branch in a larger range than its own range, it inherits its own allowed range, while the branch it is grafted on continues in its range. If several allowed ranges match, the inherited range is drawn at random among the allowed ranges contained in the range of the branch. Ex: a taxon allowed in "A" or "B" is grafted on branch in "AB"; it can inherit the range "A" or "B", but not both.

With exact matching, the plan flags two problems:

  • New_sp6 cannot be grafted (cause = "allowed_states"): its target clade is only in "BC", which matches neither "A" nor "B" exactly.
  • New_sp1, allowed in "A" only, has a low valid fraction: only 8% of the branches of its target clade are in "A", so its grafting positions are concentrated on a few short branch pieces.

With range matching, "B" matches "BC" and "A" matches "AB": all the taxa can be grafted, on a much larger share of the branches of their target clades.

3/ Graft with exact matching

We first graft with exact matching. The grafting stops, as New_sp6 has no branch available:

# ------ Exact matching: infeasible plan ------ #

grafted_error <- tryCatch(
  graft_missing_taxa(phy = toy_backbone, missing_taxa_list = taxa_ranges,
                     simmap = toy_simmap_ranges, allowed_states = c("A", "B"),
                     treat_states_as_ranges = FALSE, verbose = FALSE, seed = 1),
  error = function(e) cat(conditionMessage(e)))
#> 1 taxa have no branch available for grafting in their allowed states: none of the available branches of their target clade has a piece in these states.
#>   - New_sp6 (target clade tips: t5; allowed states: A, B)
#> Adjust 'allowed_states' (global or in missing_taxa_list), or the constraints on the branches ('include_target_clade_stem', 'Excluded_subclades', 'exclude_subclades_stem') for these taxa.

With exact matching, every range that can be used must be listed: here, we add "BC" to the global allowed_states.

# ------ Exact matching: list all the ranges ------ #

grafted_exact <- graft_missing_taxa(phy = toy_backbone, missing_taxa_list = taxa_ranges,
                                    simmap = toy_simmap_ranges, allowed_states = c("A", "B", "BC"),
                                    treat_states_as_ranges = FALSE, verbose = FALSE, seed = 1)

4/ Graft with range matching

With range matching, the global allowed_states = c("A", "B") is enough:

# ------ Range matching ------ #

grafted_ranges <- graft_missing_taxa(phy = toy_backbone, missing_taxa_list = taxa_ranges,
                                     simmap = toy_simmap_ranges, allowed_states = c("A", "B"),
                                     treat_states_as_ranges = TRUE, verbose = FALSE, seed = 1)

5/ Compare the results

We plot the updated stochastic maps, in which the grafted branches are dashed, and the grafted tips are marked with a point in the color of the range they inherited:

# ------ Compare the grafted phylogenies ------ #

# Helper: plot the updated simmap of a grafted phylogeny
plot_ranges <- function(phy_grafted, main)
{
  plot_grafted(phy_grafted, which = "edges", simmap_colors = range_colors, fsize = 0.55, main = main)
  grafted_tips <- which(phy_grafted$grafted_tips)
  tip_ranges <- phytools::getStates(phy_grafted$simmap, type = "tips")[phy_grafted$tip.label[grafted_tips]]
  ape::tiplabels(tip = grafted_tips, pch = 19, cex = 1.5, col = range_colors[tip_ranges])
}

par(mfrow = c(1, 2), mar = c(0.5, 0.5, 2, 0.5))
plot_ranges(grafted_exact, main = "A: Exact matching")
plot_ranges(grafted_ranges, main = "B: Range matching")
legend("bottomleft", legend = names(range_colors), fill = range_colors, title = "Range", bty = "n", cex = 0.8)

par(mfrow = c(1, 1), mar = c(5.1, 4.1, 4.1, 2.1))

Since the grafting process is stochastic, placement can vary, and final states of taxa with multiple allowed states may vary too (e.g., New_sp3 in "A" or "B"). The critical change between the two matching type is the differences or not that are allowed between the range of parental branch and the inherited range of the grafted taxa.

We summarize below the range of the branch where each taxon was grafted (parent_state) and the range it inherited (tip_state) with extract_grafting_info():

# ------ Ranges at grafting and inherited ranges ------ #

# Extract grafting information for the two matching types
info_exact <- extract_grafting_info(grafted_exact, missing_taxa_list = taxa_ranges)
info_ranges <- extract_grafting_info(grafted_ranges, missing_taxa_list = taxa_ranges)

# Summarize information in a data.frame
compare_ranges <- data.frame(Taxon_name = info_exact$Taxon_name,
                             Exact_parent = info_exact$parent_state, Exact_inherited = info_exact$tip_state,
                             Ranges_parent = info_ranges$parent_state, Ranges_inherited = info_ranges$tip_state)
# Identify subset sympatric speciation event: the taxon inherits a range smaller than the range of the branch
compare_ranges$Ranges_subset_sympatry <- compare_ranges$Ranges_parent != compare_ranges$Ranges_inherited
compare_ranges
#>   Taxon_name Exact_parent Exact_inherited Ranges_parent Ranges_inherited

With exact matching, the range of the branch and the inherited range are always the same.

With range matching, taxa can be grafted on larger ranges and inherit a smaller one (subset sympatry), as for New_sp2, New_sp4, and New_sp6. The diversity of available positions is also wider.

6/ Check the grafted phylogenies

The a posteriori check of check_grafting_constraints() must use the same treat_states_as_ranges as the grafting (see vignette("check_grafting")):

# ------ A posteriori check ------ #

constraints <- check_grafting_constraints(phy_grafted = grafted_ranges, phy_backbone = toy_backbone,
                                          missing_taxa_list = taxa_ranges, allowed_states = c("A", "B"),
                                          treat_states_as_ranges = TRUE, use_excluded_subclades = FALSE,
                                          verbose = FALSE)
constraints[, c("Taxon_name", "in_tree", "target_ok", "states_ok", "ranges_ok")]
#>         Taxon_name in_tree target_ok states_ok ranges_ok
#> New_sp1    New_sp1    TRUE      TRUE      TRUE      TRUE
#> New_sp2    New_sp2    TRUE      TRUE      TRUE      TRUE
#> New_sp3    New_sp3    TRUE      TRUE      TRUE      TRUE

states_ok is TRUE when the range of the taxon is one of its allowed ranges, and ranges_ok when it also respects the rule of range matching: the branch it was grafted on contains the range it inherited.
