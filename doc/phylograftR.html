Main tutorial

Quick-to-run example

A simple use-case that grafts missing taxa on a toy backbone phylogeny is available in the README of the package, and a full workflow from the data to the checked grafted phylogenies is presented in the main workflow tutorial: vignette("main_workflow").

For more advanced uses, please refer to the tutorials below.
